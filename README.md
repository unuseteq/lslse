# BestGames — модуль B

Одностраничное приложение для создания и совместного использования интерактивных досок.

## Запуск

Откройте `index.html` в браузере или запустите любой статический сервер из папки проекта:

```bash
npx serve .
```

## Возможности

- регистрация и вход с проверкой e-mail и пароля;
- список публичных досок и создание новых;
- холст фиксированного размера 1600×900;
- текст, изображение, прямоугольник, круг и линия;
- перемещение объектов мышью с ограничением по границам холста;
- сохранение досок и объектов в localStorage;
- адаптивная оболочка для мобильных экранов.

В текущей демонстрационной версии синхронизация имитируется локальным сохранением. Для подключения реального REST API и WebSocket достаточно заменить функции сохранения и обработчики событий в `app.js`.
