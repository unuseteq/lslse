Разработка Веб-приложения на стороне клиента\nВремя на выполнение модуля: 1 час 30 минут\nСтек: JavaScript, Vue, React\nЗадания:\nВам необходимо разработать одностраничное приложение (SPA) для создания и совместного использования интерактивных досок. Пользователь должен иметь возможность:\nзарегистрироваться и авторизоваться;\nсоздавать доски;\nразмещать на доске различные объекты: текст, изображение, прямоугольник, круг, линию, с возможностью вращения и управления их размерами (сохраняя соотношение сторон у изображения);\nсинхронизировать изменения через WebSocket в режиме реального времени;\nОбщие требования\nПриложение должно быть реализовано как SPA.\nВсе взаимодействия с сервером осуществляется через REST API и WebSocket.\nПри всех действиях должна быть реализована валидация на стороне сервера. Ошибки отображаются рядом с соответствующими полями, поля подсвечиваются (использовать либо локальный сервер, либо Open Server).\nДолжна быть реализована базовая навигация (например, с использованием React Router или Vue Router).\nФункциональность приложения\nАвторизация и регистрация\nПользователь должен иметь возможность зарегистрироваться и авторизоваться.\nПоля регистрации:\nemail (валидный);\nимя (только латиница);\nпароль (от 8 символов, должен содержать цифры и спецсимволы).\nПоля авторизации:\nemail;\nпароль.\nПосле успешной авторизации пользователь попадает на страницу списка публичных досок. После регистрации — на страницу входа.\nУправление досками\nПользователь может:\nсоздавать доски;\nРабота с доской\nНа доске пользователь может:\nдобавлять объекты: текст, изображение, прямоугольник, круг, линию;\nвращать и перемещать объекты;\nизменять размеры объектов (сохраняя соотношение сторон у изображений);\nвидеть все изменения в реальном времени благодаря WebSocket (использовать либо локальный сервер, либо Open Server)\nРабота с холстом\nКаждая доска должна содержать холст фиксированного размера 1600 x 900 пикселей.\nВсе объекты (текст, изображения, фигуры) должны размещаться только внутри границ холста.\nПользователю должно быть запрещено перемещать или масштабировать объекты за пределы холста.\nИзменения объекта на холсте применяются только после снятия фокуса с объекта (клик в любой области вне объекта).\nВизуально границы холста должны быть чётко обозначены на экране.
